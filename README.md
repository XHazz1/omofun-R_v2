### ⚡ 下载引擎

| 模块 | 变更 |
|------|------|
| 🔗 并发调度 | 并发下载上限 4 ➜ 8；分片任务独立调度，并行执行，不再串行等待 |
| 🔁 HLS 容错 | 片段下载失败自动重试，上限 3 次 |
| 📊 合并机制 | 片段流式合并，避免整集载入内存；合并进度稳定显示 99%，修正提前报 100% |

### 🛠 稳定性修复

- ⏱ 全部下载请求（播放列表 / 片段 / 直链）增加 **15 秒超时**，根治任务 0% 挂起
- 🔧 修复直链下载无超时保护的问题
- 🧹 修复任务失败后 `.segs` 临时文件残留的问题
- ⏳ 修复 HLS 解析期间任务状态滞留"排队中"的问题
- 🔄 修复片段重定向无深度上限的问题
- 🗑 修复删除 / 重试任务时旧临时文件未清理的问题

### 🎨 界面

- 💬 界面文本中文化（导航 / 设置 / 状态 / 选项），底层逻辑值保持英文，不影响设置读写
- 📐 窗口比例可调（0%–200%，默认 125%）
- 🔍 界面内容缩放固定 90%
- 🏷 版本信息显示为 2.0.1 v2

✦ ──────────────── ❓ 常见问题 ──────────────── ✦

<details>
<summary><b>🔍 点开看：FAQ</b></summary>

**Q1：下载任务卡在 0% 不动怎么办？**
本版已给所有下载请求加 15 秒超时，正常情况下不会再挂死。如果仍出现，重启应用后重试该任务。

**Q2：想恢复原版界面 / 逻辑？**
`resources/app.asar.bak` 是原始备份：退出应用 → 用备份覆盖 `app.asar` → 重启即可回滚。

**Q3：窗口比例怎么调？**
设置页 → 窗口比例滑块，0%–200% 可调（默认 125%）。

**Q4：杀毒软件误报怎么办？**
改版程序未签名，部分杀软可能误报。可添加信任或校验文件来源后使用。

**Q5：下载速度为什么没满带宽？**
并发上限已提到 8 线程，实际速度还受资源站服务器限速影响，属于正常现象。

</details>

### ⚙️ 环境依赖

| 工具 | 用途 |
|------|------|
| 🟢 Node.js | 运行 `@electron/asar` |

| 🛠 Inno Setup 7（可选） | 构建安装程序（zip 压缩，asar 单独不压缩） |
| 🗜 WinRAR（可选） | 压缩分发 rar |

### 📁 项目结构

```
omofun/
├── omofun.exe                  # 主程序
└── resources/
    ├── app.asar                # 应用包（主进程 + 渲染进程），补丁落点
    └── app.asar.bak            # 原始备份，回滚用
```

### 🔧 补丁工作流

```
① 解包    npx @electron/asar extract resources/app.asar <目录>
② 打补丁  修改 out/main/index.js（下载逻辑）+ out/renderer/assets/*.js（界面）
③ 校验    node --check <改动的 js 文件>
④ 重打包  npx @electron/asar pack <目录> resources/app.asar
⑤ 验证    重启应用，进程正常（约 4–5 个）、功能按预期
```

### 🛠 构建安装程序

- ⚙️ Inno Setup 配置要点：`AppVersion=2.0.1.v2`、`Compression=zip`、asar 单独 `nocompression`
- 📦 产物：`omofun-2.0.1.v2-setup.exe`
